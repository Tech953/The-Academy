# The Academy — Gameplay Trailer

## Director's treatment

- **Promise:** The Academy turns a mysterious campus RPG into a playable path through character-driven exploration, social choices, and GED learning.
- **Audience / takeaway:** YouTube viewers and Buildathon judges should understand that this is both a role-playing world and a learning game, not a terminal skin around a static course.
- **Format / runtime:** 16:9 landscape, exactly 5:00 (300 seconds), designed for a 1920×1080 export.
- **Identity:** Black CRT field, phosphor green from The Academy's existing boot screen, restrained cyan and amber state colors, JetBrains Mono for terminal language, Space Grotesk for large editorial words. The supplied Open Graph boot image is real product artwork; other interface plates are newly composed illustrations of verified game systems.
- **Hero:** The in-world terminal becomes a window into the campus; commands, people, course records, and progress move through it.
- **Motion:** Terminal cursor, route drawing, orbiting stat geometry, and five recurring mask/split transition families. Scene motifs associate across cuts, but the chapter changes are not literal object-match cuts.
- **Arc:** Boot mystery → student identity → campus navigation → people and choices → learning loop → mastery → mobile continuity → project reveal.
- **Payoff:** The opening archive resolves into a clear project identity: The Academy is an educational RPG with a campus adventure and a real learning path.
- **Audio:** One original 112 BPM synthesized electronic score, approximately 300 seconds, with a four-second fade-in and five-second fade-out. No vocals, voiceover, or separate sound effects; scene changes are not claimed to be beat-synchronized.

- Composition changes on every cut: boot plate, character record, radial stat instrument, destination directory, terminal macro, dialogue/reputation split, contradiction network, course ledger, practice close-up, progress panorama, notebook spread, context dialogue, character-sheet instrument, mobile portrait, and palette-inverted end card.
